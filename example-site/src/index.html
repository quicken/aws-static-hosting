Example site

A dependency-free site for testing the three hosting scenarios. Upload it and click through.

General hosting · public

This page. Served from the bucket root. If you can read it without signing in, the root is reachable (the gate redirects protected pages, but the landing page here is public — see below).

Public path · no login

/public/ — reachable with no session at all, because it sits under PUBLIC_PATHS (default /public).

Basic auth · the gate

/app — a protected shell. With no session you are bounced to the Cognito login and returned here afterwards. This is the login gate doing its job.

Advanced SPA · deep links

/app/dashboard — a single-page app with client-side routing. Once signed in, try a deep link straight into a route, e.g. /app/dashboard/reports/42. The gate rewrites it to the app's index.html and the client router renders the right view — a full reload, no 404.
