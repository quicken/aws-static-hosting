Example site

A dependency-free site for testing the three hosting scenarios. Upload it, then click through — Feebee will show you around.

General hosting · public landing

This page. Served from the bucket root at / with no login — the gate makes / public (PUBLIC_PATHS=/), the public front of the trail.

Public assets · no gate at all

The CSS and logo on this page load from /public/assets/. That path has its own CloudFront behaviour with no function attached — truly public static files, served to anyone at zero per-request cost. The gate never runs there. Put public assets under /public/; put pages under /app.

Basic auth · the gate

/app — a protected paddock. With no session Feebee herds you to the Cognito login and back again. This is the gate doing its job.

Advanced SPA · deep links

/app/dashboard — a single-page app with client-side routing. Once signed in, try a deep link straight into a route, e.g. /app/dashboard/reports/42. The gate rewrites it to the app's index.html and the client router renders the right view — a full reload, no 404.
